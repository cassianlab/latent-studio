# Phase 15 灵活 Skill、快捷灵感与上下文压缩

状态：已完成（当前范围）；官方服务端 Compaction 自动模式、分页目录和来源内部断点续传留待后续阶段

## 目标

- 一次同步全部六个正式图片提示词来源，并清理上游已删除或已取消来源的旧导入项。
- 工作台默认不绑定 Skill，文本与 Agent 模式可通过 `/` 为当前轮显式选择 Skill，Agent 仍可自动匹配合适 Skill。
- 文本模式可读取普通附件和参考图，并运行受控 Skill，但不暴露或执行生图工具。
- 快捷灵感保留风格、构图、镜头、光线、质感与场景模板，改为实用的中文提示词，并支持新增、编辑、删除和从提示词库导入。
- 单一共享会话使用 258k token 上下文窗口，接近上限自动压缩旧历史，压缩失败时仍可继续对话。

## 验收标准

- [x] “同步更新”刷新全部六个正式来源，并显示新增、更新、清理和失败数。
- [x] YouMind Nano Banana Pro、prompts.chat、Awesome Prompts 与 EvoLink 的导入项和检索索引会被清理，个人副本不受影响。
- [x] 工作台不再显示 Skill 选择按钮；文本与 Agent 输入 `/` 后显示可键盘操作的 Skill 建议。
- [x] 显式 Skill 只对当前轮生效，后续轮可重新选择其他 Skill；无显式选择时不携带旧 Skill ID。
- [x] 未进入压缩摘要的 Skill 指令快照和工具结果保留在会话上下文；新一轮可同时使用历史 Skill 与当前新选 Skill，不重复读取内容未变的历史 Skill。
- [x] 文本模式可上传附件、选择多张参考图并运行显式 Skill，服务端不提供生图工具。
- [x] 快捷灵感初始内容可直接组合用于生图，所有条目均可编辑和删除，可新建或从提示词库导入。
- [x] 超过提前阈值时压缩旧消息且保留近期原文；当前 0.6.0 使用本地摘要式压缩，模型压缩报错、返回空内容或返回过长内容时使用本地安全降级策略。OpenAI Responses 官方 Compaction 尚未在本阶段接入。
- [x] 发送到文本模型的最终请求始终不超过 258k 硬上限，不因压缩失败阻断新一轮对话。

## 公开测试边界

- 提示词同步 API 的来源镜像结果。
- 输入器 `/Skill` 解析与本轮提交参数。
- 快捷灵感配置的增删改查和提示词库导入。
- 对话上下文准备器的压缩、降级与硬上限。
- Agent 执行 API 在文本模式下暴露的工具集合。
