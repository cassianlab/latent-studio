# 参考图与缩略图体验修正

## 目标

- [x] 画板图片仅作为本轮临时参考图，不写入项目目录或素材库。
- [x] 生成结果、素材库和提示词库缩略图完整显示图片内容。
- [x] 素材卡片对 1 MB 及以上文件使用 MB 单位。
- [x] 图片参数支持真正的自动宽高比，并用轮廓图标说明固定比例。

## 验收标准

- [x] 画板确认后不调用素材保存接口，提交模型时使用 data URL 引用。
- [x] 本地和素材库参考图继续使用项目文件引用。
- [x] 三处图片卡片不再使用会裁切内容的 `cover` 展示方式。
- [x] 自动比例不提交固定尺寸，固定比例按钮展示对应长宽轮廓。
- [x] 1024x720、1440x900 和宽屏桌面下的亮暗主题无布局问题。
