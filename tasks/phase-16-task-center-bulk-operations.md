# Phase 16 任务中心批量管理与商业化交互

状态：已完成

## 目标

- 为任务中心增加可访问的多选、当前结果全选和批量操作。
- 批量命令由主进程统一执行，普通任务与图片任务遵循同一状态规则。
- 增加搜索、排序、队列状态和明确的批量结果反馈。
- 保持单任务详情、重命名、归档、恢复和删除行为兼容。

## 验收标准

- [x] 原生复选框支持逐项选择、当前结果全选、部分选中状态和清空选择。
- [x] 取消、重试、归档、恢复、删除只作用于当前选择中状态合法的任务。
- [x] 批量删除与批量取消需要确认，弹窗说明实际影响范围。
- [x] 批量执行返回成功、跳过和失败明细，页面显示可理解的结果反馈。
- [x] 支持按标题、ID、模型、路由和错误信息搜索，并支持稳定排序。
- [x] 全局暂停/继续反映真实队列状态，不重复调用图片队列。
- [x] 文本模型在发布图片任务前生成简短任务名，新任务名由主进程统一限制为 24 个字符。
- [x] 任务详情内可直接编辑标题，保存后同步更新列表，不打开第二层弹窗。
- [x] 打开任务详情时不自动聚焦带 Tooltip 的编辑按钮。
- [x] 1024x720、1440x900 和宽屏在浅色/深色主题下无重叠、无横向页面溢出。
- [x] TypeScript、全量测试、文件大小检查、生产构建、Electron 构建与冒烟测试通过。
