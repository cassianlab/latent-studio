依赖：`tasks/phase-2-foundation.md`

- [x] 图片参数内先选供应商、再直接选择图片模型，不打开二级窗口

- [x] 提示词优化默认跟随工作台文本模型，并支持仅本次覆盖
- [x] 设置页获取模型结果放入独立导入窗口，支持搜索、分页与批量启用
