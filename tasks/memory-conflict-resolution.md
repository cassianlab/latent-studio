# 记忆冲突决策优化

依赖：`tasks/phase-2-foundation.md`

## 目标

- [x] 记忆支持语义类别，并兼容没有类别的旧数据。
- [x] 视觉风格、色彩基调和画幅比例按排他类别解决冲突。
- [x] 项目记忆优先于全局记忆，同一作用域使用较新记忆。
- [x] 本轮明确要求优先于长期记忆。
- [x] 被覆盖记忆保留在库中，但不进入模型上下文。
- [x] 界面显示类别、覆盖状态、覆盖来源和实际注入数量。

## 验收标准

- [x] “喜欢复古风”和“喜欢科技风”同为全局记忆时，仅较新的条目注入。
- [x] 项目复古风可以覆盖更新更晚的全局科技风。
- [x] 普通不同标题记忆继续叠加，不因新增规则被误删。
- [x] 浏览器预览与 Electron 正式存储均保留记忆类别。
- [x] 1024x720、1440x900 和 1920x1080 的浅色、深色界面无溢出；弹窗底部操作始终可见。

## 验证记录

- [x] `npm test`：107 个测试文件、608 个测试通过。
- [x] `npx tsc -b --pretty false`、`npm run check:file-size`、`git diff --check` 通过。
- [x] `npm run build`、`npm run build:app`、`npm run smoke:app` 通过。
- [x] Playwright 实测创建复古风与科技风记忆：科技风生效，复古风显示覆盖原因，实际注入数量不增加。
