# Phase 11 Agent 流式对话与状态反馈修复

状态：已完成

## 目标

- Agent 与图片智能规划统一使用已验证的流式文本模型通道，避免兼容网关的非流式请求返回 HTTP 502。
- Agent 回复按文本增量即时显示；图片任务确认仍保持显式人工确认。
- 文本、Agent 和图片任务等待状态提供清晰、稳定且支持减少动态效果设置的动画反馈。
- 发送新消息或图片目标后，界面自动定位到当前对话，不要求用户手动滚动。
- 任务详情与原型反馈弹窗保持内容清晰，背景可辨识且不使用模糊滤镜。

## 验收标准

- [x] AgentRunner 优先使用流式生成并逐个转发 `text_delta`，最终结果仍包含完整文本和工具调用。
- [x] Agent 主进程只向 Renderer 暴露带 `runId` 的文本增量，不暴露供应商原始响应或凭据。
- [x] 取消 Agent 会停止当前模型流；确认图片任务后仍可继续接收 Agent 后续文本。
- [x] 图片模式智能规划使用同一流式模型服务，不再依赖非流式生成入口。
- [x] 文本与 Agent 等待状态显示三点动画，流式正文显示光标；减少动态效果时动画停止。
- [x] 文本和 Agent 新消息自动滚动到底部；图片模式新目标自动定位到当前目标。
- [x] Agent 图片确认 IPC 的请求结构与主进程读取结构一致。
- [x] 任务详情和原型反馈遮罩无 blur、无入场动画，透明度不超过 0.42。
