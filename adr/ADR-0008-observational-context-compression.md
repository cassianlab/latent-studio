# ADR-0008 观察式上下文压缩

- 状态：accepted
- 日期：2026-09-21

## 决策

会话压缩使用项目现有文本模型的普通生成接口，把较早消息整理为结构化观察记录，并保留最近原文。观察记录固定包含当前目标、事实与约束、当前决定和偏好、产物与工具结果、未完成事项及变更记录。同一会话切换模型时继续使用相同观察和原始消息边界；切换会话时加载该会话自己的状态。

工作台不探测或调用 OpenAI `/responses/compact`，也不向后续请求发送供应商私有的压缩项。旧会话中的官方压缩数据只读取可见摘要，并在下一次压缩后迁移为观察式状态。详细方案比较见 `docs/context-compression-research.md`。

压缩摘要优先保留文件路径、URL、模型与 Skill ID、画幅和数量等精确值，以及用户明确标记为必须、禁止或改为的约束。新消息推翻旧决定时，新值成为当前状态，旧值只保留在变更记录。模型压缩超过 30 秒、返回空内容或无效内容时，使用有界的本地原文摘录，保证会话可以继续。

## 代价与边界

- 压缩会额外产生一次普通文本模型调用，其语言质量取决于当前文本模型。
- 本地保底模式不做语义推断，只保证有界、可读和可继续，因此界面会明确标注降级原因。
- 完整原始消息继续保存在项目会话中；压缩只改变发送给模型的上下文投影。
- 不直接引入 Mastra、LangChain、LlamaIndex 或 LLMLingua，避免第二套消息存储、Python 推理运行时和额外模型下载。
