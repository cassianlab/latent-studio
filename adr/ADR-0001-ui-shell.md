# ADR-0001 UI Shell 原型

- 状态：proposed
- 日期：2026-09-12

## 决策

原型采用 React + Vite，使用 Lucide 图标、Radix Dialog/Tooltip 原语和 Motion 过渡。页面用本地 mock 数据串起工作台、素材、文档、提示词、Skills、任务、设置与记忆。工作台输入器采用浮动岛结构：模式、上下文、图片优化标准或 Agent Skill、长文本输入和发送控制属于同一个交互边界。图片标注先用轻量 Canvas 交互模拟，生产阶段再锁定 Konva/React Konva 并执行大图、长笔迹、连续撤销性能门禁。

## 原因

原型重点是验证信息架构和关键流程，而不是提前实现 Electron、数据库或真实 Agent 循环。将模型、搜索、文件和任务行为限定在 mock port，便于用户验收后逐步替换。

## 待确认

- 图片标注工具栏的密度与颜色预设。
- 版本对比采用并排还是滑块为默认视图。
