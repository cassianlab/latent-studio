# ADR-0007 长期记忆冲突决策

- 状态：accepted
- 日期：2026-09-20

## 决策

长期记忆保存可选的语义类别：通用规则、视觉风格、色彩基调、画幅比例、角色设定、构图与镜头、禁止与排除、工作习惯。视觉风格、色彩基调和画幅比例是排他类别；同一类别最终只注入一条。旧数据没有类别时，根据标题优先、正文补充的方式推断，避免因为正文包含“禁止”等描述而覆盖标题表达的真实类别。

冲突按固定顺序决策：本轮用户明确要求优先于长期记忆；项目记忆优先于全局记忆；同一作用域、同一排他类别中，以 `updatedAt` 较新的条目为准，时间相同时使用较高版本。非排他类别按规范化标题判断冲突，不同标题可以同时注入。

被覆盖记忆继续保存在记忆库中并保持启用状态，但不进入模型上下文。界面显示其类别、“已覆盖”状态和实际生效条目；“实际注入”统计只计算冲突处理和预算限制后的最终条目。

## 代价与边界

- 类别推断用于兼容旧数据，用户在编辑器中明确选择类别后，以用户选择为准。
- 本轮明确要求只影响本轮模型调用，不会自动重写长期记忆。
- 排他类别是产品规则；若未来需要同时叠加多种视觉风格，应新增组合机制，而不是放宽现有冲突规则。
- 记忆仍受最大条目数和字符预算限制，未进入上下文的低优先级条目不等同于发生语义冲突。
