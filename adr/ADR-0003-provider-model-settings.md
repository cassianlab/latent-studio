# ADR-0003 连接与模型设置存储

- 状态：accepted
- 日期：2026-09-13

连接配置和模型配置存放在应用用户数据目录的全局 SQLite 中。每条连接独立保存服务商类型、Base URL、API Key 密文和并发上限，因此同一服务商可以配置多个 Key，文本模型与图片模型也能绑定不同连接。Renderer 只能读取不含密钥的连接摘要和模型能力，API Key 仅通过主进程的 `safeStorage` 写入或在后续模型请求时解密。

模型能力使用显式字段，不根据模型 ID 或显示名称推断；旧数据库通过幂等迁移补充模型类型列。这样会增加设置 IPC 和迁移代码，但能避免跨供应商切换时静默改变凭据、费用或数据去向。

最近项目也使用同一全局数据库的 `recent_projects` 表；JSON 文件实现只作为兼容端口和测试替身保留。
