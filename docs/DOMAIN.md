# 领域词汇

- **项目**：文档、素材、会话、任务、输出和项目记忆的边界。
- **会话**：项目内可在文本、图片和 Agent 模式切换的连续上下文。
- **任务计划**：智能批量或 Agent 产生的可检查任务集合。
- **素材**：项目中的图片或文件，可标记角色、场景、道具或参考图。
- **提示词资产**：可插入的提示词、带变量模板或风格片段。
- **Skill**：仅由 Agent 调用的能力包；原型只展示授权与信任状态。
- **记忆**：可编辑、可停用的稳定偏好或项目约束，不等于聊天记录。
- **图片版本**：从原图或结果派生的新图片，保留父子关系。
- **模拟端口**：为原型提供确定数据和交互反馈的本地函数，不代表正式服务能力。
